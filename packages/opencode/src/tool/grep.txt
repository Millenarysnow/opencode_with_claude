A powerful content search tool built on ripgrep.

Usage:
- ALWAYS use grep for search tasks. NEVER invoke `grep` or `rg` as a shell command. The grep tool has been optimized for correct permissions and ripgrep handling.
- Supports full regex syntax (e.g., "log.*Error", "function\s+\w+")
- Filter files with the include parameter (e.g., "*.js", "*.{ts,tsx}")
- Returns file paths and line numbers with at least one match, sorted by modification time
- Pattern syntax: uses ripgrep (not GNU grep) — literal braces need escaping (use `interface\{\}` to find `interface{}` in Go code)
- When you are doing an open-ended search that may require multiple rounds of globbing and grepping, use the task tool instead — it keeps the intermediate tool output out of your context.
- If you need to identify/count the number of matches within files, use the shell tool with `rg` (ripgrep) directly only when the grep tool cannot express what you need. Prefer grep.
- You have the capability to call multiple tools in a single response. Speculatively perform multiple independent searches as a batch when it can narrow the question faster.
