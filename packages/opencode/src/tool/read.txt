Reads a file from the local filesystem. You can access any file directly by using this tool.
Assume this tool is able to read all files on the machine. If the user provides a path to a file assume that path is valid. It is okay to read a file that does not exist; an error will be returned.

Usage:
- The filePath parameter must be an absolute path, not a relative path.
- By default, this tool reads up to 2000 lines starting from the beginning of the file.
- You can optionally specify a line offset and limit (especially handy for long files), but it's recommended to read the whole file by not providing these parameters.
- When you already know which part of the file you need, only read that part. This can be important for larger files.
- Results are returned with each line prefixed by its line number as `<line>: <content>`. For example, if a file has contents "foo\n", you will receive "1: foo\n". This matches a "cat -n"-style format.
- Any line longer than 2000 characters is truncated.
- This tool can read image files (e.g. PNG, JPG, WebP). When reading an image, the contents are presented visually as attachments so you can reason over them as a multimodal model.
- This tool can read PDF files (.pdf) and returns them as file attachments.
- This tool can read Jupyter notebooks (.ipynb files) and returns the cells (code, markdown) with their outputs combined.
- This tool can also read directories: entries are returned one per line (without line numbers), with a trailing `/` for subdirectories. To read a directory, pass its path as `filePath`; no offset/limit line slicing applies.
- If you read a file that exists but has empty contents you will receive a system reminder warning in place of file contents.
- Call this tool in parallel when you know there are multiple files you want to read — it is always better to batch independent reads into a single response.
- Avoid tiny repeated slices (e.g. 30-line chunks). If you need more context, read a larger window.
- If you are unsure of the correct file path, use the glob tool to look up filenames by glob pattern, or the grep tool to find specific content in large files.
